# رفيق الحفظ — جزء عمّ

هذا تطبيق ويب شخصي للتدرب على جزء عمّ. بعد تنزيل ملفات التطبيق والنموذج، يجري تحليل صوت الميكروفون على جهاز الآيفون داخل Safari؛ لا يرسل التطبيق التلاوة إلى GitHub أو إلى خدمة تصحيح سحابية. بعد إنهاء القراءة ينطق ملخص المراجعة بصوت عربي متوفر على الجهاز، ويمكن تجربة سؤال صوتي عن الملاحظات والنتيجة وموضع التوقف إذا كان Safari يدعم التعرف المحلي بالعربية.

## النشر المجاني على GitHub Pages

1. على الكمبيوتر، نزّل ملف النسخة المحدّثة وافتحه لفك الضغط.
2. ثبّت GitHub Desktop من `https://desktop.github.com/` وسجّل الدخول إلى حساب GitHub.
3. في GitHub Desktop اختر **File → New repository**. اكتب `quran-companion` في خانة الاسم، واختر مكانًا يسهل الوصول إليه، واترك إنشاء README و`.gitignore` غير محدد، ثم اضغط **Create repository**.
4. افتح مجلد المشروع الجديد في مستكشف الملفات. انسخ **كل ما بداخل المجلد الذي فُك ضغطه** إليه، ووافق على استبدال README إن ظهر السؤال.
5. ارجع إلى GitHub Desktop. اكتب `Add Quran companion files` في خانة **Summary** واضغط **Commit to main**.
6. اضغط **Publish repository**. يجب أن يكون المستودع عامًا لأن GitHub Pages مجاني للمستودعات العامة. محتوى التطبيق والنص القرآني وملفات الترخيص ستكون ظاهرة للناس على الويب؛ لا تضع أي ملفات شخصية فيه.
7. من صفحة المستودع على GitHub افتح **Settings → Pages**. في **Build and deployment** اختر **GitHub Actions** كمصدر.
8. افتح تبويب **Actions** وانتظر اكتمال مهمة **Build and deploy to GitHub Pages** باللون الأخضر. أثناء البناء تُنزّل GitHub النموذج إلى ملفات الموقع.
9. ستظهر وصلة الموقع في **Settings → Pages**. افتحها في Safari على الآيفون.
10. اسمح باستخدام الميكروفون عند الطلب، واضغط **ابدأ التسميع** مع الاتصال بالإنترنت لأول مرة كي يُنزّل النموذج. انتظر حتى تظهر حالة الميكروفون ثم أوقف الجلسة.
11. في Safari اضغط **مشاركة → إضافة إلى الشاشة الرئيسية → إضافة**. بعد أن يكتمل تنزيل الملفات، جرّب فتحه دون إنترنت. قد يحذف iOS الملفات المؤقتة إذا احتاج مساحة.

للميكروفون يلزم عنوان HTTPS. GitHub Pages يوفر عنوانًا آمنًا، لكنه يستضيف ملفات الموقع علنًا. تسجيلات أحمد العجمي تُبث من EveryAyah عند الضغط على زر الاستماع، لذا يتطلب الاستماع اتصالًا بالإنترنت. هذا لا يرسل تلاوة المستخدم؛ التصحيح يبقى محليًا. المحادثة الصوتية لا تعمل إن لم يوفر Safari تعرفًا محليًا بالعربية، والتطبيق لا يتحول تلقائيًا إلى خدمة سحابية. الردود الصوتية تستخدم نطق الجهاز؛ والأسئلة الصوتية الحالية محدودة بموضوع جلسة التسميع وليست محادثة لغوية مفتوحة.

## الحقوق والحدود

- نص الآيات من [Tanzil](https://tanzil.net/download/)، بالخط العثماني، دون تعديل؛ إسناده وشروطه في `src/public/data/tanzil-attribution.txt`.
- المحرك وبياناته من [Tilawa](https://github.com/yazinsai/tilawa). النموذج وبيانات phoneme بترخيص NPL-1.2 غير التجاري والمشاركة بالمثل؛ الترخيص في `src/public/licenses/NPL-1.2.txt`.
- النص العثماني هو مرجع العرض. مطابقة الصوت والتنبيهات احتمالية ولا تثبت صحة التجويد أو مخارج الحروف؛ راجع مع معلّم متقن.
- زر الاستماع يشغل تلاوات أحمد العجمي من [EveryAyah](https://www.everyayah.com/recitations_ayat.html) مباشرةً، ولا يضمّن التسجيلات داخل ملفات الموقع. يذكر EveryAyah أن الملفات الأصلية مصدرها [QuranicAudio](https://quranicaudio.com).
- خيار «قراءة السورة كاملة» يشغّل البسملة ثم آيات السورة بالتتابع من EveryAyah، ويتطلب اتصالًا بالإنترنت.
